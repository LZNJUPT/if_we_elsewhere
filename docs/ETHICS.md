# 伦理准则（ETHICS）

IfWe 处理的是真实的人际关系与真实的人的情绪，这决定了本项目有几条不可退让
的边界。

## 1. 服务对象是「想复盘的人」，不是「想说服别人的人」

本工具的价值在于帮助**使用者本人**理解一段关系、练习表达、与遗憾和解。
它不适合、也不应用于：

- 说服、施压或「挽回话术」演练后投向真实对方的操控性沟通；
- 替代与真实对方的直接沟通；
- 评估、审判他人的行为。

## 2. 反对「赛博招魂」

把逝去或断裂的关系在模型里无限续命，是一种自我伤害。我们建议：

- 给自己设定使用边界（比如每周固定时段）；
- 把推演当作书写的另一种形式，写完即合上；
- 若发现自己沉溺于推演而回避现实生活，请停下来，并考虑寻求专业支持
  （求助资源见 [../DISCLAIMER.md](../DISCLAIMER.md)）。

## 3. 数据涉及真实他人

你导入的聊天记录通常包含对方的言行。请：

- 仅在合法、正当的范围内处理这些数据；
- 不公开、不传播、不用于训练或骚扰（LICENSE 附加条款明令禁止）；
- 分享截图或成果时，先抹去一切可识别信息。

## 4. AI 生成内容的风险

数字人格的一切回应都是模型对「你提供的记忆」的即兴推演。它会自信地犯错，
也可能说出对方永远不会说的话。请始终保持「这是创作，不是实录」的清醒。

## 5. 设计上的自我约束（我们在代码里做的）

- 推演与真实记录物理隔离（`sim_*` 命名空间），UI 明确标注「模拟估计量 · 非事实」；
- 关系状态只降置信度、不出结论，界面不提供「他会怎么想」式的断言文案；
- 隐私门禁（check_privacy）作为发布硬性关卡，宁可推迟发布也不带隐私上线；
- 不内置任何抓取能力，不降低「获取他人数据」的门槛。

## 6. 如果你正在困难时期

这个项目由一段真实的失去出发而写成。我们知道此刻读到它的人可能正处在类似
的位置。工具只能陪你到工具能到的地方，剩下的路请交给真实世界的人——朋友、
家人，或专业帮助。求助资源见 [../DISCLAIMER.md](../DISCLAIMER.md)。
