README 顶部引用了本目录的 `demo.gif`。当前版本已用**虚构示例数据**录制完成

## 30 秒 GIF 分镜建议（demo 数据）

| 时间 | 画面 | 操作 | 预期效果 |
|---|---|---|---|
| 0-4s | 终端 | `python run.py demo` 回车 | 服务启动横幅 |
| 4-8s | 浏览器 | 界面加载完成 | 左侧线列表、右侧对话框 |
| 8-14s | 界面 | 点「＋ 新的一条线」→「回到过去某天」 | 时间轴出现：月度消息量条、转折点标记（活跃高峰/重要事件） |
| 14-20s | 界面 | 点某个月 → 预览当月对话（「先看看那时你们说了什么」）→ 在改写框输入「那天我直接打了电话过去」 | 回忆预览 + 改写卡 |
| 20-27s | 界面 | 发送一条消息 → 数字人格回复（或表情包） | 对话气泡 + 关系五维状态条变化 |
| 27-30s | 界面 | 定格在五维状态面板 | 「模拟估计量 · 非事实」标注可见 |

## 录制提示

- 工具：Windows: Win+G / ShareX；macOS: Cmd+Shift+5；或 OBS。
- 输出：GIF，宽 ≤ 960px，< 8MB（GitHub README 友好）。
- 终端字体调大；深色主题即可（项目界面即深色）。
- 示例数据发消息需要 `LLM_API_KEY`（`run.py demo` 后 `run.py server` 前设置）；
  也可以只录「时间轴选点 + 历史回放」部分，无需 Key。
