# docs/demo —— 演示素材占位

> ⚠️ **红线：演示 GIF/截图必须且只能用 `sample_data/` 的虚构示例数据录制。**
> 严禁使用任何真实聊天记录录演示——包括「只露一半」「打码」的形式。

README 顶部引用了本目录的 `demo.gif`。当前版本已用**虚构示例数据**录制完成
（真实界面截图序列：新建线 → 回到过去时间轴 → 选月份看回忆预览 → 填改写句 →
建线进入对话窗）。更换演示内容时，参考下方分镜重新录制即可。

## 30 秒 GIF 分镜建议（demo 数据）

| 时间 | 画面 | 操作 | 预期效果 |
|---|---|---|---|
| 0-4s | 终端 | `python run.py demo` 回车 | 服务启动横幅 |
| 4-8s | 浏览器 | 界面加载完成 | 左侧线列表、右侧对话框 |
| 8-14s | 界面 | 点「＋ 新的一条线」→「回到过去某天」 | 时间轴出现：月度消息量条、转折点标记（活跃高峰/重要事件） |
| 14-20s | 界面 | 点某个月 → 预览当月对话（「先看看那时你们说了什么」）→ 在改写框输入「那天我直接打了电话过去」 | 回忆预览 + 改写卡 |
| 20-27s | 界面 | 发送一条消息 → 数字人格回复（或表情包） | 对话气泡 + 关系五维状态条变化 |
| 27-30s | 界面 | 定格在五维状态面板 | 「模拟估计量 · 非事实」标注可见 |

## 录制提示

- 工具：Windows: Win+G / ShareX；macOS: Cmd+Shift+5；或 OBS。
- 输出：GIF，宽 ≤ 960px，< 8MB（GitHub README 友好）。
- 终端字体调大；深色主题即可（项目界面即深色）。
- 示例数据发消息需要 `LLM_API_KEY`（`run.py demo` 后 `run.py server` 前设置）；
  也可以只录「时间轴选点 + 历史回放」部分，无需 Key。

## Web 导入向导分镜（v0.2 补录，demo 数据）

> 同样必须用 `tests/samples/` 或 `sample_data/` 的**合成/虚构数据**录制。

| 时间 | 画面 | 操作 | 预期效果 |
|---|---|---|---|
| 0-3s | 界面 | 左侧栏点「导入记录」 | 三步向导弹窗：① 上传 |
| 3-8s | 界面 | 拖入合成 CSV（如 tests/samples/wecomsg_sample.csv） | 自动上传并跳到 ② 预览：格式/跨度/类型分布/脱敏预估 |
| 8-14s | 界面 | 查看 A/B 下拉候选与脱敏样例，选择「你（A）/对方（B）」 | 候选账号带消息数与占比；样例含脱敏占位符 |
| 14-20s | 界面 | 点「确认导入」 | ③ 导入结果：门禁摘要（时间序/双人占比/脱敏残留/未知发送者）全绿 |
| 20-25s | 界面 | 点「完成」关闭 | 回到主界面；`data/tmp_import/` 临时文件已清空 |

录制提示：向导不依赖 LLM Key；如需演示门禁失败分支，可用一份只有单方
发言的合成文件（G3 双人占比会不过）。

- `demo.gif` 文件名保持不变，README 无需改动。
- 建议同时在 Release 页附一段 30-60 秒 mp4。
