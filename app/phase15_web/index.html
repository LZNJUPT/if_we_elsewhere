导入聊天记录

① 上传 ② 逐份确认 + 合并预览 ③ 导入结果
拖拽文件到这里，或点击选择（可多选） 支持 .jsonl / .json / .csv / .txt / .md / .log / .docx，单份 ≤ 50MB，单批 ≤ 12 份 不同应用分别导出的记录可以一起选：导入后会按时间戳自动合并、重复消息自动去重 全程本机处理，文件不会被上传到任何远端
支持这些来源：
  • chatlab / WeFlow 导出的 JSONL
  • WeChatMsg（MemoTrace / 留痕）导出的 CSV
  • Telegram Desktop 导出的 result.json
  • 整理好的 .txt / .md（每行一条：2024-09-11 09:30:00 张三: 内容）
  • Word .docx（段落或「时间｜发送者｜内容」表格）
PDF 不解析：体检会识别出来并提示你转存为 txt 或 docx。只支持「你自己合法导出」的文件。
