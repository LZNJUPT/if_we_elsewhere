# sample_data —— 虚构示例数据

> **本目录全部内容为虚构**：人物（沈星然、林晚语）、对话、日期、事件均属创作，
> 与任何真实人物、真实关系无关。请勿对号入座。

| 文件 | 说明 |
|---|---|
| `chat.sample.jsonl` | 79 条虚构双人对话（2026-07-06 ~ 2026-07-22，约 2.5 周），格式与 chatlab/WeFlow 导出一致，供 `python run.py demo` 导入 |
| `persona_v1_A.json` | 虚构人物「沈星然」（A 侧）的人格档案（L/M/S/U 四层） |
| `persona_v1_B.json` | 虚构人物「林晚语」（B 侧）的人格档案 |

## 用途

- `python run.py demo`：不导入任何真实数据，用这里的内容跑通「导入 → 分析 →
  聊天界面」全链路
- 自检：确认你的环境依赖安装正确、各 Phase 能正常出数

## 想用自己的数据？

不要修改这里。按 README 的快速开始：把**你自己合法导出**的 JSONL 放到
`data/raw/`，走 `run.py init` 即可；你的数据在 `data/`（已被 .gitignore 排除，永不入库）。
